Q16. Shortest Path in an Unweighted Graph
Problem Statement

You are given an undirected graph with:

N vertices
E edges
Source vertex S
Destination vertex D

Find the minimum number of edges required to travel from S to D.

Since all edges have equal weight (1), we use Breadth First Search (BFS) to find the shortest path.

Sample Input
5 5
1 2
1 3
2 4
3 4
4 5
1 5

Input Meaning
N = 5 vertices
E = 5 edges

Edges:
1 - 2
1 - 3
2 - 4
3 - 4
4 - 5

Source = 1
Destination = 5

Graph
      1
     / \
    2   3
     \ /
      4
      |
      5

Shortest Path

Possible path:

1 → 2 → 4 → 5


Edges used:

3


Another path:

1 → 3 → 4 → 5


Edges used:

3


Minimum edges:

3

Sample Output
3

Approach

Use Breadth First Search (BFS).

Why BFS?

In an unweighted graph:

Every edge has equal cost.


BFS explores nodes level by level.

The first time we reach a node, we have found its shortest distance.

Step-by-Step Logic
Step 1

Create adjacency list.

List<Integer>[] g

Step 2

Store all graph edges.

Because the graph is undirected:

g[a].add(b);
g[b].add(a);

Step 3

Initialize distance array.

dist[i] = -1


Meaning:

Node not visited yet.

Step 4

Start BFS from source.

dist[S] = 0

queue.add(S)

Step 5

Remove node from queue.

int u = queue.poll();

Step 6

Visit all neighbors.

If neighbor is not visited:

dist[v] = dist[u] + 1;


Add into queue.

Step 7

Continue BFS until queue becomes empty.

Step 8

Answer:

dist[D]


output : 3
